Privacy Policy

Last updated: November 7, 2026

1. Overview

Source Code Editor is an open-source browser extension developed by Nicolas Dos Santos. It runs entirely in your browser. The developer operates no server for it and receives no data from it: the extension does not collect, transmit, sell or share any personal data.

2. Data Collection and Usage

The extension contains no analytics, telemetry, advertising or tracking of any kind.

  • Your files, the repositories you clone and everything you edit stay on your device.
  • The extension never sends your code, your file names or your browsing history to the developer or to any third party.

3. Data Stored in Your Browser

The extension stores the following data locally, in your browser, and nowhere else:

  • Your workspace: the files you create, import or clone are kept in the browser's private file system (OPFS), together with the list of recently opened folders and the permission handles of the local folders you opened.
  • Preferences and layout: settings, color theme, open editors, layout and cursor positions, kept in the browser's local storage.
  • Git author: the name and email you enter for your commits, kept in your settings.
  • Access tokens: when you give an access token to reach a private Git repository (or sign in with GitHub), it is kept in storage.local of the extension only. It is never put in synchronized storage, in settings, in repository addresses or in exports, and you can delete it at any time with Git: Forget Access Tokens or by removing the extension.

Uninstalling the extension removes this data.

4. Network Requests

The extension only contacts the servers you ask it to:

  • Git servers: the repository address you clone, pull from or push to (for example github.com or gitlab.com, or your own server), and only for those operations. Your access token, if any, is sent to that server and to no other.
  • GitHub sign-in: if you choose to sign in with GitHub, the extension uses GitHub's device flow: it contacts github.com to obtain a code, you authorize the application on github.com, and GitHub gives the extension an access token (scope repo, which GitHub requires to push to private repositories). You can revoke it at any time in your GitHub settings, under Applications.

The Git servers and GitHub handle your data under their own privacy policies.

5. Permissions Justification

  • storage: to keep your preferences, workspace state and access tokens on your device.
  • activeTab / tabs: to read the address of the current tab and open the editor (in a tab or a standalone window) on the repository you are viewing.
  • contextMenus: to add Open repository in Source Code Editor on GitHub and GitLab pages.
  • Host access to all sites: Git servers do not allow requests from browser extensions' pages by default; this access lets the editor reach the server of any repository you choose to clone or push to. It is only used for those requests.
  • nativeMessaging (optional): only if you install the optional Local Companion program and grant this permission, so that the editor can work with your disk and Git directly. It is off by default.

6. Third-Party Services

The extension contains no third-party tracking scripts, analytics tools or advertising networks.

7. Open Source and Contact
