Privacy Policy

Last updated: October 4, 2026

1. Overview

Source Code Viewer is an open-source browser extension developed by Nicolas Dos Santos. Your privacy is paramount: the extension is designed to run entirely locally in your browser and does not collect, transmit, or monetize any user data.

2. Data Collection and Usage

The extension does not collect, track, or transmit any personal data, browsing history, visited URLs, IP addresses, or network traffic.

  • All source code viewing, beautification, XML/JSON parsing, and font inspection happen entirely on your machine.
  • No remote server communications are initiated by the extension for analytics, telemetry, or user profiling.

3. Local Storage

The extension uses local browser storage (chrome.storage.local) solely to save your local UI preferences:

  • Selected editor theme (light/dark themes)
  • Font size preference
  • Word-wrap and search options

This preference data remains strictly on your device and is never synchronized to any external server.

4. Permissions Justification

  • activeTab / tabs / scripting: Required strictly to retrieve the current page source when requested and format it in the viewer.
  • contextMenus: Allows opening the formatted source viewer directly from the browser context menu.
  • storage: Allows preserving your display preferences between sessions.

5. Third-Party Services

The extension contains no third-party tracking scripts, analytics tools, or advertising networks.

6. Open Source and Contact

The full source code of this extension is licensed under GPL-3.0 and publicly auditable on GitHub: https://github.com/Kobee1203/source-viewer-web-extension .

If you have any questions regarding this policy, feel free to open an issue on GitHub.
